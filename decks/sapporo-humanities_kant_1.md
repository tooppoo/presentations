# カントが生きた近代ヨーロッパ

* 哲学史上の、二つのピーク
  * ソクラテス、プラトン、アリストテレスの古代ギリシア

#  近代哲学が直面した二大難問

* 自然科学が著しく発展する一方で浮上する二大難問
* 物と心の関係をどう考えるか（物心問題）
  * 人間に自由意志はあるのか？
  * 微や道徳の根拠は何か？
  * 心は物によって作り出せるか？

# 主観と客観は一致できるか

* 主観はどうやって客観的世界に一致する知を獲得できるのか（主客一致問題）
  * 自然科学は「一致する」ことを問いとせず前提にすることで発展してきた
* デカルトの「我思う、ゆえに我あり（コギト・エルゴ・スム）」
  * 「私」の存在は論証したものの、主客一致には神を持ち出さざるを得なかった
* 「客観的な知」の正当性に関わる問題

# カントを震撼させたヒュームの警告

* イギリス経験論 =  人間は主観から出られない
  * ヒュームによる因果律への批判
* 大陸合理論 = 経験に依らない客観的秩序を認識できる
  * スピノザ：因果的必然性を理性によって認識できる
  * ライプニッツ：予定調和説、十分理由律

# カントは何を「批判」したのか

* 「批判」＝「（理性の）能力とその限界を厳しく吟味すること」
* 理性は物事を推理する能力を持つが、しばしば「究極の真理」を求めて「暴走」する
* 純粋理性批判 = 経験とは独立して、理性の能力とその限界を吟味する

# 主観の共通規格は存在する

カントの基本戦略

- 主観世界（現象界）が客観世界そのもの（物自体、叡智界）と一致することはない
- どの主観も、一定の共通規格を持つ
- 客観的認識（皆が共有しうる認識）は成り立つ

> わたしたちが直観する事物は事物そのものではない。(...)これらの特性や関係は現象であり、それ自体として存在するものではなく、わたしたちのうちに存在することができるだけのものだからである。

# 感性と悟性の働き

- 感性 = 感覚器官で受けた刺激を、空間・時間という枠の中で位置づける能力
  - 空間・時間は感性の「形式（もともと備わった共通規格）」
- 直感 = 感性によって位置づけられた感覚
- 悟性 = 感覚を統合して「判断」をもたらす能力
  - 多様な感覚を概念として整理する。カテゴリー能力。

# コペルニクス的転回

- コペルニクス的転回
  - 素朴な認識：客観がまずあり、それを主観が写し取る（客観→主観）
  - カントの議論：主観の枠組み（感性・悟性）が、現象としての客観を作り出す（主観→客観）
- 感性や悟性の形式は、人間にア・プリオリ（先天的）に備わったものである
  - これらの形式はア・プリオリである = 経験によるものではない
- 主客問題の解体：主観と客観を一致させるのではなく、主観同士を一致させる
